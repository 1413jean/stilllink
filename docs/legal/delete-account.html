刪除帳號與資料

生效日期：2026 年 10 月 2 日　·　適用於 StillLink for macOS（含 StillLink Beta）

StillLink 沒有帳號，所以沒有帳號需要刪除。你的所有資料都只存在你自己的 Mac 上，開發者手上沒有任何副本。要刪除資料，照下面任一種方式操作即可。

1.在 App 內清空所有資料

  1. 打開 StillLink。
  2. 前往 設定 → 資料。
  3. 點選 清空所有資料，並確認。

清空後立即生效，無法復原。如果之後還想保留這些資料，請先匯出 .stilllink 備份檔。

2.完整移除 App 與資料

如果你想把 StillLink 從 Mac 上完全移除：

  1. 結束 StillLink。
  2. 把「應用程式」資料夾中的 StillLink.app 拖到垃圾桶。
  3. 在 Finder 選單列選 前往 → 前往檔案夾⋯（⇧⌘G），依序前往並刪除：
    • 資料夾：~/Library/Application Support/StillLink
    • 測試版資料夾（若有使用）：~/Library/Application Support/StillLink Beta
    • 偏好設定：~/Library/Preferences/app.stilllink.mac.plist
  4. 清空垃圾桶。

3.會刪除的資料

  • 所有命盤，包括姓名、出生日期、出生時間、出生地
  • 筆記
  • 照片與頭像
  • App 設定

4.不會被刪除的資料

  • 你自己匯出的備份檔（.stilllink）：這些檔案在你選擇的位置，App 不會去動它們。如果也要刪除，請自行找到並刪除，包括你放在外接硬碟或雲端硬碟上的副本。
  • GitHub 端的紀錄：App 檢查更新時，GitHub 會收到標準的請求資訊（例如 IP 位址與 App 版本），由 GitHub 依其 隱私權聲明 處理。這部分不包含你在 App 中輸入的任何內容。

除此之外，開發者沒有保存你的任何資料，因此也沒有其他需要申請刪除的資料。

5.如果未來加入帳號

StillLink 未來可能加入「使用 Apple 登入」或「使用 Google 登入」。若加入帳號功能，本頁會在功能上線前更新，說明如何刪除帳號，以及帳號刪除後哪些資料會被移除。

刪除資料

最後更新：2026 年 10 月 2 日

一句話：StillLink 沒有帳號，所以沒有帳號要刪。所有資料都在你的 Mac 上，你可以自己全部清掉。

方法一：在 App 裡清空（最簡單）

  1. 打開 StillLink，到「設定 → 資料」
  2. 想留一份的話，先按「備份…」
  3. 按「清空所有資料」，再確認一次

清空後沒辦法復原。

方法二：連 App 一起移除

  1. 結束 StillLink，把「應用程式」裡的 StillLink 丟到垃圾桶
  2. 在 Finder 按 ⇧⌘G，貼上 ~/Library/Application Support/，刪掉 StillLink（測試版是 StillLink Beta）資料夾
  3. 再前往 ~/Library/Preferences/，刪掉 app.stilllink.mac.plist（測試版是 app.stilllink.mac.beta.plist）
  4. 清空垃圾桶

會刪掉什麼

  • 所有命盤、備註、照片和頭貼
  • 你的個人檔案和所有設定

不會刪掉什麼

  • 你自己匯出的 .stilllink 備份檔（要刪請自己找到它）
  • GitHub 在你檢查更新時留下的一般連線紀錄，由 GitHub 依其政策處理

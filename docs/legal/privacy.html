隱私權政策

生效日期：2026 年 10 月 2 日　·　適用於 StillLink for macOS（含 StillLink Beta）

簡單說：StillLink 是一款由個人開發者 Jean 製作的免費紫微斗數排盤 App。

  • 你輸入的所有資料只存在你自己的 Mac 上，不會上傳到任何伺服器。
  • 沒有帳號、沒有登入、沒有雲端同步。
  • 沒有數據分析、沒有廣告、沒有追蹤。
  • 唯一的網路連線是向 GitHub 檢查與下載 App 更新。

1.我們蒐集哪些資料

開發者不蒐集任何你的個人資料。你在 App 中輸入或建立的內容，只會儲存在你的裝置上，開發者無法看到，也無法取得。這些內容包括：

  • 命盤資料：姓名、出生日期、出生時間、出生地
  • 你寫下的筆記
  • 你加入的照片與頭像
  • App 的偏好設定

2.資料存放在哪裡

所有資料都存放在你 Mac 的本機資料夾：

  • 正式版：~/Library/Application Support/StillLink
  • 測試版：~/Library/Application Support/StillLink Beta

偏好設定由 macOS 存放在 ~/Library/Preferences/app.stilllink.mac.plist。

StillLink 目前沒有帳號系統，也沒有雲端同步。資料不會離開你的 Mac，除非你自己匯出備份檔並移到其他地方。

3.命盤如何計算

排盤使用開源函式庫 iztro，完全在你的 Mac 上本機運算。出生資料不會為了計算而送到任何外部服務。

4.網路連線與第三方服務

StillLink 只會在一種情況下連上網路：檢查與下載 App 更新。更新功能使用 Sparkle 更新框架，連線對象為 GitHub（api.github.com、github.com）。

這類連線會像一般網路請求一樣，讓 GitHub 收到標準的請求資訊，例如你的 IP 位址與 App 版本。這些資訊由 GitHub 依其政策處理，詳見 GitHub 一般隱私權聲明。更新請求不包含你的命盤、筆記、照片或任何你輸入的內容。

StillLink 沒有使用任何會蒐集資料的第三方 SDK，包括數據分析、廣告、當機回報或追蹤工具。

5.備份檔

你可以自行從 App 匯出備份檔（副檔名 .stilllink）。備份檔包含你的 App 資料，要存在哪裡由你決定，例如本機、外接硬碟或你自己選用的雲端硬碟。一旦你把備份檔放到第三方服務，該檔案就受該服務的隱私政策規範。若備份檔含有他人的出生資料，請妥善保管。

6.輸入他人資料

如果你為家人、朋友或其他人排盤，你輸入的是他們的個人資料。請在輸入前取得對方同意。這些資料一樣只存在你的 Mac 上。

7.保存與刪除

資料會一直保存在你的 Mac 上，直到你自己刪除。因為開發者手上沒有你的任何資料，刪除完全由你掌控：

  • 在 App 中前往 設定 → 資料 → 清空所有資料；或
  • 刪除 App，並一併刪除上述資料夾與偏好設定檔。

詳細步驟請見 刪除資料說明。

8.資料安全

由於資料只存在本機，資料安全取決於你的 Mac 本身。建議開啟 FileVault 磁碟加密、設定登入密碼，並妥善保管匯出的備份檔。

9.未來可能的變更

StillLink 未來可能加入「使用 Apple 登入」或「使用 Google 登入」等帳號功能。若加入這類會處理個人資料的功能，本政策會在該功能上線前先行更新，清楚說明會蒐集哪些資料、如何使用，以及如何刪除。

本政策若有其他修改，會更新本頁上方的生效日期。
